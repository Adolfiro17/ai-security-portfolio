Run it

You need Python 3.11 or newer and Git. Nothing else: the model is a deterministic mock, so there is no key to set up.

CommandWhat it does
./start.shCreate an environment, run the tests, the seeded attack and all eight guided challenges
./start.sh lab 3Run one challenge (or all)
./start.sh siteServe this site at http://localhost:8000
.\start.ps1The same, on Windows PowerShell
git clone https://github.com/Adolfiro17/ai-security-portfolio.git
cd ai-security-portfolio/01-secure-ai-agent
./start.sh
Why a mock model? It is built to be fully manipulated. If the hardened agent still stops the attack, the proof rests on the architecture, not on a model happening to behave well.

Roadmap

The labs are built to merge into one application once all eight modules exist.

  1. Now. Module 1 as a complete lab: handout, guided challenges, findings log, assessment export, instructor solutions, and this site.
  2. Next. Modules 2 to 8, each built by hand with the same loop and the same file layout, so they can run on their own.
  3. Then. A shared module contract and a single launcher, so all labs run from one app with one findings report, in the style of an integrated training environment.

About

Built by Adolf Sey as a portfolio of attack-and-defend AI security projects. Everything uses fictional data, planted fake secrets and local-only execution. The insecure code is insecure on purpose: do not deploy it, and never point these techniques at systems you do not own.

The format draws on ideas from public AI security courses and labs. See the attribution notes.
