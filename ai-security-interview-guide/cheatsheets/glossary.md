# Glossary

| Term | Meaning |
| --- | --- |
| AIBOM | AI bill of materials: models, datasets, dependencies and their provenance |
| ASR | Attack success rate in testing |
| Attenuated delegation | Passing on only a subset of one's permissions |
| Confused deputy | A trusted component tricked into misusing its authority |
| Denial of wallet | Abuse that drives up cost rather than taking a service down |
| Direct prompt injection | The user's own input contains instructions that subvert the system |
| Indirect prompt injection | Instructions hidden in data the model reads (documents, web, email, tool output) |
| Embedding inversion | Reconstructing text from its vector |
| Guardrail | A probabilistic filter around model input or output |
| Lethal trifecta | Private data, untrusted content and an exfiltration path in one agent |
| MCP | Model Context Protocol, a standard for connecting models to tools and data |
| Membership inference | Determining whether a record was in the training data |
| Model extraction | Copying model behaviour through queries |
| Policy gateway | Deterministic enforcement point for tool calls |
| Rug pull | A tool or server changes its behaviour after approval |
| Tool poisoning | Malicious instructions in tool descriptions or metadata |
| Taint tracking | Marking data from untrusted sources and restricting what it can influence |
| Wilson interval | A confidence interval for a proportion, reliable at small sample sizes |
