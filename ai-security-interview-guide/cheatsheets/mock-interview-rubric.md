# Mock interview rubric

Score each answer 0 to 3 on each row. Aim for 2 or more everywhere before an interview.

| Dimension | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- |
| Structure | Rambling | Some order | Clear steps | Leads with the answer, then layers |
| Threat awareness | Generic | Names risks | Names attacker paths | Prioritises by impact and likelihood |
| Controls | "Use a guardrail" | Lists controls | Matches controls to threats | Distinguishes deterministic from probabilistic |
| Practical detail | None | One example | Concrete config or code | Shows a test or evidence |
| Trade-offs | None | Mentioned | Costs and limits stated | Gives a recommendation with reasons |
| Measurement | None | "We would test" | Names metrics | Uses intervals and sample sizes honestly |
| Communication | Jargon | Some plain language | Adapts to the audience | Translates to business impact |
| Honesty about limits | Overclaims | Some caveats | States what it does not solve | Names residual risk and next steps |

## Drill

1. Pick a question and answer it in 60 seconds.
2. Have a partner ask two follow-ups from the file and one they invent.
3. Score, then redo the weakest dimension.
